# site_comercial

Site comercial estático, composto por HTML, CSS e JavaScript puro.

## Estrutura

- `index.html` — marcação e conteúdo da página
- `styles.css` — estilos responsivos
- `app.js` — interações da página

## Execução local

Abra `index.html` em um navegador ou use qualquer servidor estático local.
